# smit34.ru — сайт интернет-провайдера СмИТ

Одностраничный сайт провайдера СмИТ (Волгоград, Красноармейский район).
React + Tailwind, без npm-зависимостей в рантайме: исходник — один `index.html`,
на продакшн уезжает собранная версия.

**Продакшн:** https://smit34.ru

---

## Быстрый старт

```bash
# правим index.html — это источник правды (JSX + классы Tailwind)
# затем собираем и выкладываем:
bash deploy.sh
```

`deploy.sh` вызывает `build.mjs` и копирует результат на сервер по SSH.
**Заливать `index.html` напрямую нельзя** — в продакшн-версии нет ни Babel, ни Tailwind CDN.

Разовая подготовка инструментов сборки:

```bash
cd d:/tmp/smitbuild
npm i @babel/standalone tailwindcss@3.4.17 esbuild
```

## Как устроена сборка

| Этап | Что делает |
|---|---|
| `build.mjs` → Babel | компилирует JSX из `<script type="text/babel">` в `dist/js/app.<hash>.js` |
| `build.mjs` → esbuild | минифицирует результат |
| `build.mjs` → Tailwind CLI | собирает CSS по классам из `index.html` в `dist/css/app.<hash>.css` |
| `build.mjs` → HTML | вырезает CDN-скрипты Babel и Tailwind, подставляет ссылки на собранные файлы |
| `build.mjs` → пререндер | открывает страницу в headless-Chrome и кладёт готовую разметку внутрь `#root` |

### Пререндер

Контент рисует React, поэтому без пререндера краулер видел в HTML около 170 символов.
Финальный шаг сборки открывает собранную страницу в headless-Chrome (`puppeteer-core`
+ системный Chrome), ждёт отрисовки карточек тарифов и сохраняет разметку в `#root`.

- данные (`tariffs.json`, `news.json` и прочие) во время пререндера берутся с боевого
  сайта через локальный прокси — в HTML попадают актуальные цены и новости;
- inline-стили анимаций (`opacity`, `transform`) вычищаются, иначе краулер увидел бы скрытый контент;
- разметка AI-виджета вырезается — он подключается своим скриптом;
- пропустить шаг: `node build.mjs --no-prerender`.

Результат: в HTML **8165 символов текста**, H1, 7 H2 и 12 H3. FCP на мобильном стал
даже быстрее (768 → 584 мс) — браузер рисует контент, не дожидаясь выполнения JS.

Хэш в имени файла позволяет кэшировать js/css вечно. Старые сборки на сервере
чистятся автоматически (хранятся три последние).

**Динамические классы Tailwind** (`bg-${news.categoryColor}-100` и подобные) сборщик не видит —
они перечислены в `safelist` внутри `build.mjs`. Добавляете новый цвет категории — впишите его туда.

## Данные сайта

Контент правится в JSON-файлах рядом с `index.html` — пересборка для этого не нужна,
достаточно залить файл по scp:

| Файл | Что содержит |
|---|---|
| `tariffs.json` | тарифы Дом/Бизнес: цена, скорость, фичи, обложки и видео |
| `news.json` | новости: дата, категория, анонс, HTML-контент, обложка |
| `equipment.json` | оборудование: название, цена, картинки для светлой и тёмной темы |
| `paidServices.json` | прайс-лист платных услуг |
| `services.json` | описания услуг (ТВ, видеонаблюдение, компьютерный сервис) |

Все загружаются с cache-buster, поэтому правки видны сразу.

## Прямые ссылки

| URL | Что открывает |
|---|---|
| `/testspeed` | замер скорости, активна вкладка «СмИТ» |
| `/covermap` | карта покрытия |

Работают и как хеш: `#testspeed`, `#covermap`.

Разделы старого сайта склеены с блоками главной постоянными редиректами:
`/news/` → `/#news`, `/services/` → `/#services`, `/help/` → `/#help`,
`/company/` → `/#about`, `/contacts/` → `/#contacts`.

### SEO

- `robots.txt` и `sitemap.xml` в корне сайта
- canonical `https://smit34.ru/`, `meta robots`, geo-метки
- JSON-LD: `WebSite` + `InternetServiceProvider`/`LocalBusiness` (адрес, телефоны, часы работы)
- Open Graph и Twitter Card, картинка `/images/og-image-2026-08.jpg` (1200×630).
  **Дата в имени файла обязательна:** соцсети кэшируют превью по URL, при замене баннера
  меняйте имя файла, иначе VK и Telegram продолжат отдавать старое изображение
- файлы подтверждения прав: `yandex_faab79665a981959.html`, `google082e623b3df5d9f3.html`
