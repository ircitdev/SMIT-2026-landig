# smit34.ru — сайт интернет-провайдера СмИТ

Одностраничный сайт провайдера СмИТ (Волгоград, Красноармейский район).
React + Tailwind, без npm-зависимостей в рантайме: исходник — один `index.html`,
на продакшн уезжает собранная версия.

**Продакшн:** https://smit34.ru

---

## Быстрый старт

```bash
# правим index.html — это источник правды (JSX + классы Tailwind)
# затем собираем и выкладываем:
bash deploy.sh
```

`deploy.sh` вызывает `build.mjs` и копирует результат на сервер по SSH.
**Заливать `index.html` напрямую нельзя** — в продакшн-версии нет ни Babel, ни Tailwind CDN.

Разовая подготовка инструментов сборки:

```bash
cd d:/tmp/smitbuild
npm i @babel/standalone tailwindcss@3.4.17 esbuild
```

---

## Как устроена сборка

| Этап | Что делает |
|---|---|
| `build.mjs` → Babel | компилирует JSX из `<script type="text/babel">` в `dist/js/app.<hash>.js` |
| `build.mjs` → esbuild | минифицирует результат |
| `build.mjs` → Tailwind CLI | собирает CSS по классам из `index.html` в `dist/css/app.<hash>.css` |
| `build.mjs` → HTML | вырезает CDN-скрипты Babel и Tailwind, подставляет ссылки на собранные файлы |

Хэш в имени файла позволяет кэшировать js/css вечно. Старые сборки на сервере
чистятся автоматически (хранятся три последние).

**Динамические классы Tailwind** (`bg-${news.categoryColor}-100` и подобные) сборщик не видит —
они перечислены в `safelist` внутри `build.mjs`. Добавляете новый цвет категории — впишите его туда.

## Данные сайта

Контент правится в JSON-файлах рядом с `index.html` — пересборка для этого не нужна,
достаточно залить файл по scp:

| Файл | Что содержит |
|---|---|
| `tariffs.json` | тарифы Дом/Бизнес: цена, скорость, фичи, обложки и видео |
| `news.json` | новости: дата, категория, анонс, HTML-контент, обложка |
| `equipment.json` | оборудование: название, цена, картинки для светлой и тёмной темы |
| `paidServices.json` | прайс-лист платных услуг |
| `services.json` | описания услуг (ТВ, видеонаблюдение, компьютерный сервис) |

Все загружаются с cache-buster, поэтому правки видны сразу.
